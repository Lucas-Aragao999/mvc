# Documentação inicial

Este diretório guarda o material de entrada do projeto: handoff, visão do produto, requisitos, escopo, restrições, arquitetura inicial e critérios de sucesso.

Os documentos devem explicar o problema, os usuários, o escopo mínimo, as decisões técnicas, as integrações e os pontos pendentes. Preserve documentos históricos relevantes e sinalize informações obsoletas.
