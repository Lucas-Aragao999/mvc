# Preparação do projeto

Objetivo: executar a etapa 1 do roadmap, criando Express com EJS em `cadastro-produtos/` e instalando Sequelize e SQLite.

Arquivos afetados: aplicação gerada, `.gitignore`, roadmap e contexto em `DEV/docs/` (pacote operacional existente neste repositório).

Etapas: gerar o scaffold; instalar dependências; comentar código em português; validar sintaxe, resposta HTTP e renderização EJS; registrar resultados.

Aceitação: `npm start` inicia a aplicação e GET `/` retorna HTTP 200 com a página inicial. Nenhum model ou CRUD nesta etapa.

Riscos: instalação de SQLite depende de binários compatíveis com Node. Preservar os arquivos existentes e não realizar commits.
