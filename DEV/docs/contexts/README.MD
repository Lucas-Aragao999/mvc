# Contextos de sessão

Este diretório registra o estado deixado por cada sessão de IA para que outro agente ou desenvolvedor consiga continuar o trabalho.

Use `Context_dd_mm_aaaa.md`. Em mais de uma sessão no mesmo dia, atualize o arquivo existente. Informe objetivo, resumo, arquivos afetados, validações, decisões, pendências e próximos passos.

Não registre tokens, credenciais, conteúdo de `.env` ou outros dados sensíveis.
